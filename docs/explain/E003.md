# E003: unresolved function

The model calls a function that is neither a DataFusion built-in nor in the adapter's
stub pack. Declare it in derive.toml so planning can continue; stubs are never
executed, only their return type matters.

## Broken

```sql
select order_id, my_udf(amount) as adjusted from {{ ref('orders') }}
```

## Fixed

```toml
# derive.toml
[[stub]]
name = "my_udf"
returns = "double"        # or "arg0" for the first argument's type
deterministic = true
```

For an aggregate, add `kind = "aggregate"`, and `idempotent = true` if duplicate input
rows cannot change its result (like `max`).
