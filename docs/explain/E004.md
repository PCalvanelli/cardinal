# E004: unresolved relation or column

The compiled SQL reads a relation that is not in the manifest, or a column that is not
in the upstream relation's columns.

- Relations: run `dbt compile` so the manifest covers every model and source.
- Columns of sources come from `target/catalog.json` (`dbt docs generate`) or from
  `columns:` in the source's YAML. Without either, Derive cannot plan models that name
  the source's columns.

## Broken

```yaml
sources:
  - name: shop
    tables:
      - name: orders     # no catalog entry and no columns listed
```

## Fixed

```sh
dbt docs generate
```

or list the columns:

```yaml
      - name: orders
        columns:
          - name: order_id
            data_type: integer
```
