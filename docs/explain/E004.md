# E004: unresolved relation

Layer: **graph**, every ref() and declared relation resolves.

The compiled SQL reads a relation that is not in the manifest, so Cardinal can't follow
the edge to it. The model is not checked by the node or operator layers, and its
dependents see an unknown input (reported once as G004).

This usually means the manifest is out of date, or the SQL names a table directly
instead of through `ref()` or `source()`.

## Broken

```sql
select * from analytics.stg_orders     -- a table name, not a ref
```

## Fixed

```sql
select * from {{ ref('stg_orders') }}
```

then run `dbt compile`, so the manifest covers every model and source.
