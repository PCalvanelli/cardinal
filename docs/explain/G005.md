# G005: suppression matches no finding

Layer: **code**, each model's file: its compiled SQL exists and parses.

A `-- cardinal: allow(CODE) reason: ...` comment no longer suppresses anything: the SQL
changed, or the finding was fixed. Stale suppressions hide future findings on that
line, so remove them.

A suppression applies to its own line, or to the next line when the comment stands
alone. A reason is required; without one the finding is still reported.

## Broken

```sql
select order_id, sum(amount) as total   -- cardinal: allow(G001) reason: legacy
from {{ ref('order_items') }}
group by order_id
```

## Fixed

```sql
select order_id, sum(amount) as total
from {{ ref('order_items') }}
group by order_id
```
