# E005: unsupported SQL

Derive's planner cannot handle a construct in this model yet. The rest of the project is
still analyzed, and this model's dependents see an unknown input (reported once as
G004). Please report the construct with the message shown.

## Workaround

Declare the model's grain so its dependents can be analyzed:

```yaml
models:
  - name: weird_model
    meta:
      derive:
        grain: [id]
```
