# E001: missing compiled SQL

Layer: **code**, each model's file: its compiled SQL exists and parses.

The manifest has no `compiled_code` for this model, so Cardinal cannot analyze it. This
happens when the manifest came from `dbt parse` rather than `dbt compile`, or when the
model failed to compile.

## Fix

```sh
dbt compile
dbt docs generate   # for column types
cardinal check
```
