# G013: count(*) counts unmatched rows of an outer join

Layer: **operator**, each join, filter, aggregate, window and set operation, checked against the keys of what it reads.

A left join keeps every row of its left side. A left row with no match appears once,
with nulls in the right side's columns. `count(*)` counts rows, so it counts that row
too: a customer with no orders gets an order count of 1, not 0.

G013 is reported when an aggregate reads a left or right join (through projections and
aliases), the side the join fills with nulls can have several rows per preserved row (so
the count is meant to count them), every GROUP BY column comes from the preserved side,
and the count counts every row: `count(*)`, `count(1)`, or a column of the preserved
side. It is not reported when a `WHERE` on the null-filled side already drops the
unmatched rows (that is G011).

## Broken

```sql
select c.customer_id, count(*) as order_count
from {{ ref('stg_customers') }} c
left join {{ ref('stg_orders') }} o on c.customer_id = o.customer_id
group by c.customer_id
```

## Fixed

Count a column of the joined side that is never null on a matched row, such as its key
or join column. `count(x)` skips nulls, so unmatched customers count 0:

```sql
select c.customer_id, count(o.order_id) as order_count
from {{ ref('stg_customers') }} c
left join {{ ref('stg_orders') }} o on c.customer_id = o.customer_id
group by c.customer_id
```
