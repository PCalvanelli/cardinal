# G004: grain is unknown

Derive could not determine a key for one or more models. It is reported once per root
cause, listing the models it affects. Common causes:

- a source or seed with no declared key (no `unique` test, no `meta.derive.grain`);
- an operator that loses the grain, such as `UNION ALL` without a discriminator column,
  `UNNEST`, or `GROUPING SETS`;
- an upstream model that could not be planned (see its E-code);
- a Python model.

Models with unknown grain are never reported for G001 or G002: Derive prefers saying
"unknown" to guessing. `derive coverage` ranks the causes by how many models each
would unlock.

## Broken

```yaml
sources:
  - name: shop
    tables:
      - name: order_items     # no key declared
```

## Fixed

```yaml
sources:
  - name: shop
    tables:
      - name: order_items
        meta:
          derive:
            grain: [order_id, line_id]
```
