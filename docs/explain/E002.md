# E002: SQL does not parse

The model's compiled SQL does not parse in the project's dialect (taken from
`metadata.adapter_type`, or `dialect` in derive.toml). If the SQL runs in your
warehouse, the parser lacks support for this syntax: please report it with the line
shown. The model's dependents are analyzed with unknown input.

## Broken

```sql
select order_id,, amount from orders
```

## Fixed

```sql
select order_id, amount from orders
```
